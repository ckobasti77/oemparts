### 1.5 Fontovi (P7) — `app/fonts.ts`

```ts
import localFont from "next/font/local";

// Archivo Expanded 125 (naslovi), statični woff2 iz _izvor/autodelovi/assets/fonts → app/fonts/
export const archivo700 = localFont({
  src: "./fonts/archivo-expanded-700.woff2", weight: "700", style: "normal",
  display: "swap", variable: "--font-archivo-700", fallback: ["Arial", "sans-serif"],
});
export const archivo600 = localFont({
  src: "./fonts/archivo-expanded-600.woff2", weight: "600", style: "normal",
  display: "swap", preload: false, // naslovi sekcija su ispod prvog ekrana
  variable: "--font-archivo-600", fallback: ["Arial", "sans-serif"],
});

// Public Sans (tekst), varijabilni wght 100–900, iz @fontsource-variable/public-sans/files/.
// Dve familije: latin PRVA i bez prilagođenog rezervnog fonta (inače bi č/ć/š/ž/đ pali na Arial).
export const publicSansLatin = localFont({
  src: "../node_modules/@fontsource-variable/public-sans/files/public-sans-latin-wght-normal.woff2",
  weight: "100 900", style: "normal", display: "swap",
  variable: "--font-ps-latin", adjustFontFallback: false,
  declarations: [{ prop: "unicode-range", value: "<latin opseg tačno iz wght.css>" }],
});
export const publicSansExt = localFont({
  src: "../node_modules/@fontsource-variable/public-sans/files/public-sans-latin-ext-wght-normal.woff2",
  weight: "100 900", style: "normal", display: "swap",
  variable: "--font-ps-ext", // adjustFontFallback "Arial" (podrazumevano) → bez CLS
  declarations: [{ prop: "unicode-range", value: "<latin-ext opseg tačno iz wght.css>" }],
});
```

- **Imena fajlova i opsezi.** K02 proverava tačna imena fajlova i prepisuje `unicode-range` iz `node_modules/@fontsource-variable/public-sans/wght.css`. Očekivano:

- **`<html>`:** `className={[archivo700, archivo600, publicSansLatin, publicSansExt].map(f => f.variable).join(" ")}`.
- **CSS:** `--font-sans: var(--font-ps-latin), var(--font-ps-ext), Arial, sans-serif` (§3.11).

## 3. Dizajn sistem (tamni, jednostavniji, O3)

### 3.0 Pravac i DNA
- **Teza:** „Noćni tehnički list“.
  - Grafitna podloga, topla boja teksta, jedan narandžasti signal za sledeći korak.
  - Široki Archivo naslovi velikim slovima nose mesto.
  - 3D renderi delova i auta su jedini spektakl, a sve oko njih je mirno.
  - Odbija tamni „shop šablon“ sa karticama ikona, neonom i staklom.
- **design_system:** tokeni ispod.
- **design_style:**
  - raspoloženje: miran, precizan, radionički, noćni;
  - kompozicija: levo poravnato; na desktopu tekst levo i objekat desno, na telefonu jedna kolona po redu iskaz → akcija → objekat;
  - slike: samo renderi, bez ljudi, stock-a i AI fotografija;
  - interakcija: čvrsta, bez odskakanja;
  - glas: iskusan kolega, „vi“, kratko.
- **visual_effects:** intenzitet `subtle-accent`, performanse `lightweight`. Uključeno je samo hero pretapanje na skrol. WebGL, čestice, parallax i staklo nisu (zamućenje u header-u je funkcionalno).
- **Ostaje iz starog:** night paleta, ink, narandžasta `#FF6B1A`, Archivo Expanded 700/600 velikim slovima, Public Sans, Phosphor regular, osvetljena gornja ivica (elevacija), linija otkrivanja 18 %, `panel` jezik, stil podvučenog linka, fokus 2 px.
- **Izbačeno:** K01-13.
- **design-taste dial-ovi:** VARIANCE 4 (početna) / 3 (ostalo), MOTION 3, DENSITY 4.
- **Craft floor zabrane:** bez eyebrow natpisa iznad naslova, bez gradijent teksta, bez obojene leve ivice > 1 px, bez šablona „velika brojka“, bez emoji-ja, bez sistemskog pisma kao display-a. Brojevi sekcija samo gde redosled nosi informaciju (koraci kupovine i saradnje).

### 3.3 Razmaci, raster i širine
- **Osnova:** Tailwind `--spacing: 0.25rem` (4 px). Unutar komponenti 4/8/12/16/24.
- **Margine i gutter:**
  - `--margin: clamp(1rem, 4vw, 3rem)` → 16 px na 390, 48 px na 1440.
  - `--gutter: clamp(1rem, 1.7vw, 1.5rem)` → 16 / 24.
- **Sadržaj:**
  - `--container-content: 80rem` (1280 px).
  - `--pad: max(var(--margin), calc((100% - 80rem) / 2))` → 80 px sa strane na 1440.
  - `--container-reading: 45rem` (≈ 68ch) za pravne tekstove i uvode.
- **Ritam:**
  - `--space-section: clamp(4rem, 2.886rem + 4.571vw, 7rem)` → 64 / 112 px (padding-block sekcije).
  - `--space-block: clamp(1.5rem, 1.129rem + 1.524vw, 2.5rem)` → 24 / 40 (naslov → sadržaj).
  - `--space-stack: clamp(1rem, 0.814rem + 0.762vw, 1.5rem)` → 16 / 24.
  - Više prostora iznad naslova nego ispod.
- **Breakpointi:** `sm 30rem (480)`, `md 48rem (768)`, `lg 64rem (1024)`, `xl 80rem (1280)`, `2xl 90rem (1440)`.
- **Mreže kartica:**

  | Mreža | < 768 | 768–1279 | ≥ 1280 |
  |---|---|---|---|
  | sistemi i grupe | 2 kolone | 3 | 5 |
  | marke | 1 | 2 | 2 (poslednja preko cele širine ili 3+2) |

- **Header:** `--header-h` 56 px (< 1024) / 64 px.
- **Donja traka:** `--bottom-bar-h` 64 px + `env(safe-area-inset-bottom)` ispod 1024 px. Postavlja se atributom `data-bottom-bar` na `<html>` iz server layout-a, bez `:has()`.

- Ivice su uvek 1 px (`line`, `line-strong`, `control`). Debljinu 2 px imaju samo fokus i aktivna crta navigacije.
- Elevacija na tamnom je osvetljena gornja ivica plus kratka kontaktna senka. Bez sjaja i širokih zamućenja.
  - `--shadow-rest: inset 0 1px 0 0 rgb(241 236 227 / .04)` — paneli i kartice.

  - `--shadow-button: inset 0 1px 0 rgb(255 255 255 / .24)` — gornja ivica primarnog dugmeta; nestaje na pritisak.

## 5. Pokret

### 5.1 Šta animira šta

| Šta | Ko | Kako |
|---|---|---|
| Reveal blokova i naslova sekcija | GSAP core (lenjo) + `RevealEngine` | opacity 0 → 1, `y` 16 px → 0 (12 px ispod 768), 520 ms, `expo.out`; okidač: sredina elementa pređe liniju 18 % iznad dna |
| Reveal mreža i listi (stagger) | isto, grupa | 60 ms između stavki, poslednja kreće najviše 180 ms posle prve (paket ≤ 700 ms), redosled dokumenta |
| Reveal dugog teksta | isto, varijanta `fade` | samo opacity, 360 ms |
| Hero pretapanje (P9) | GSAP + ScrollTrigger (lenjo, samo početna) preko `ScrollCrossfade` | sloj „rasklopljen“ opacity 0 → 1, `scrub: 0.5`, `ease: "none"`; sklopljen ostaje na opacity 1 |
| Sažimanje header-a | CSS + IO sentinel (bez GSAP-a) | podloga `opacity` 0 → 1 (220 ms, ease-out); logo `scale(1.06)` → 1 (220 ms) |
| Meni (dialog) | GSAP preko `useSheetMotion` | ulaz: panel opacity 0 → 1 + `y` −8 → 0, 280 ms, `expo.out`; stavke stagger 30 ms (≤ 150 ms); izlaz: opacity → 0 + `y` −8, 180 ms, `power2.in`, pa `dialog.close()`; scrim opacity 220 ms |
| Hover i press | CSS | boje 80 ms linear; pritisak `translateY(1px)` 140 ms `ease-snap`; kartica −2 px i render 1,03 |
| Disclosure | CSS keyframes | sadržaj opacity + 8 px, 220 ms; strelica 180°, 220 ms |
| Fokus | — | trenutno, bez animacije |

- **Gde se reveal koristi:**
  - Početna: sekcije 2–9 (naslovi su `Reveal`, mreže `RevealGroup`); hero ne.
  - Asortiman: sekcije i mreže. Sistem: članci grupa. Vozila: paneli marki. Saradnja i Kako kupiti: koraci. O nama: `fade`.
- **Gde se reveal ne koristi:** forme (upit), kontakt, pravne strane, 404, header, meni, donja traka, footer, elementi koje GSAP već transformiše.
- **Pravilo:** reveal ide na omotač (`li`), a hover transform na unutrašnji `<a>`, da se ne sudare.

### 5.2 Trajanja i ease (`lib/motion.ts` ↔ CSS)
```ts

export const REVEAL_TALL = 0.6;           // viši od 60 % ekrana → okidač je vrh, ne sredina
export const REVEAL = { durationS: 0.52, fadeS: 0.36, liftPx: 16, liftNarrowPx: 12,
                        narrowMax: "(max-width: 47.99rem)", stepMs: 60, budgetMs: 180, ease: "expo.out" };
export const DUR = { instant: 0.08, quick: 0.14, base: 0.22, panel: 0.28, panelExit: 0.18 };
export const EASE = { out: "expo.out", in: "power2.in", inOut: "power2.inOut", scrub: "none" };
export const MEDIA = { reduce: "(prefers-reduced-motion: reduce)", ok: "(prefers-reduced-motion: no-preference)",
                       desktop: "(min-width: 64rem)" };
export function staggerDelayMs(index: number, count: number, t = REVEAL): number {
  if (index <= 0 || count <= 1) return 0;
  const step = Math.min(t.stepMs, t.budgetMs / (count - 1));
  return Math.round(Math.min(index, count - 1) * step);
}
```

### 5.4 Algoritam `RevealEngine` (K02)
1. **Pokretanje.** `useEffect` zavisi od `usePathname()`, da ponovo skenira posle navigacije.
   - Ako `matchMedia(MEDIA.reduce).matches`: ne radi ništa i sluša promenu.
   - Inače posle `requestIdleCallback` (timeout 1500 ms; rezerva `setTimeout(…, 200)`) radi `await loadGsap()`. Ako uvoz padne, izlazi i ništa nije sakriveno.
2. **Mete.** `[data-reveal="block"], [data-reveal-group] > [data-reveal="item"]`; samo najspoljnije; preskače potomke `[data-reveal="off"]`.
3. **Prva odluka.** Jedan `IntersectionObserver` (`rootMargin: "0px 0px -18% 0px"`, `threshold: [0, 0.5]`) prati sve mete. Prvi callback za svaki element (WeakSet `seen`):
   - `rect.top >= innerHeight` (ceo ispod ekrana): `gsap.set(el, { opacity: 0, y: lift })`, `data-reveal-state="pending"`;
   - inače: ostaje vidljiv, `done`, `unobserve`.

   Ništa što je na ekranu se nikad ne sakriva. Nema bljeska. LCP je bezbedan.
4. **Kasniji callback za `pending`:**
   - `isIntersecting` i (`ratio >= 0.5` ili `visina > 0.6·innerHeight`): ide u paket;
   - nije u preseku i `rect.bottom < 0` (preskočen brzim skrolom ili skokom): odmah vidljiv, bez animacije (`gsap.set`, `clearProps`).
5. **Paket.** Grupisanje po najbližem `[data-reveal-group]` (ili sam element), sortiranje po redu u dokumentu, pa:

   `gsap.to(items, { opacity: 1, y: 0, duration, ease: "expo.out", stagger: step/1000, overwrite: "auto", clearProps: "opacity,transform", onComplete: state = "done" })`.
6. **Sigurnosne mreže (failsafe):**
   - `focusin` u `pending` element: odmah vidljiv (opacity 0 zadržava fokusabilnost; **nikad `autoAlpha` ili `visibility`**);
   - `beforeprint`: sve vidljivo;
   - promena na reduced motion: sve vidljivo;
   - pasivni `scroll` sa rAF: svaki `pending` čiji je `rect.top < 0.82·innerHeight` se otkriva;
   - na dnu strane (`scrollY + innerHeight ≥ scrollHeight − 2`) se otkrivaju svi `pending` na ekranu (poslednji ekran nikad ne dostiže liniju);
   - čišćenje efekta (navigacija ili unmount): `disconnect`, ubijanje tween-ova, svi `pending` vidljivi.
7. **Bez JS-a i pri štampi:** ništa nije sakriveno (nema CSS pred-skrivanja).

### 5.5 Hero pretapanje (P9, K03)
- **Struktura:**
  ```text
  <ScrollCrossfade
    base={<HeroPicture stanje="assembled"/>}
    overlay={<HeroPicture stanje="exploded" lenja/>}/>
  ```
  Overlay je `absolute inset-0 opacity-0`, a pod `motion-reduce:hidden` je `display:none`, pa se lenja slika ni ne učita.
- **ScrollTrigger:** u efektu `loadScrollTrigger()`, zatim `gsap.matchMedia(scope)`:
  - `desktop` (≥ 1024): `trigger: hero sekcija, start: "top 64px", end: "+=60%"`;
  - telefon i tablet: `trigger: okvir slike, start: "top 75%", end: "bottom 40%"`.
  - Oba: `gsap.fromTo(overlay, { opacity: 0 }, { opacity: 1, ease: "none", scrollTrigger: { …, scrub: 0.5, invalidateOnRefresh: true } })`.
- **Osvežavanje:** `ScrollTrigger.refresh()` jednom posle `document.fonts` `loadingdone` i `load` slike (rAF, koalesovano).
- **Bez JS-a i pod reduced motion:** stoji sklopljen auto.
- **LCP:** sklopljena slika je uvek `opacity: 1`, `fetchpriority="high"`, `loading="eager"`; nikad nije meta reveal-a ni GSAP-a.

### 5.6 Header, meni, hover i press (K03)
- **Header:**
  - `<div data-header-sentinel class="absolute top-0 h-6 w-px pointer-events-none" aria-hidden>` je prvi u `body`;
  - `HeaderState` (client) prati ga IO-om i postavlja `data-condensed="true|false"` na `<header>`;
  - SSR stanje je `false`, a `@media (scripting: none) { .header-surface { opacity: 1 } }`;
  - visina header-a se ne menja (bez layout pomeranja); menjaju se samo opacity podloge i transform logoa.
- **Meni:** `MobileMenu` (client) dobija logo i linkove kao `children` iz server header-a (K01-24).
  - Otvaranje: `showModal()` → `enter()`.
  - Escape: `cancel` → `preventDefault` → `exit()` → `close()` → fokus na dugme.
  - Klik na scrim (`::backdrop` područje) zatvara.
- **Hover i press:** samo CSS (`transition-control`, `card-link`). Nema „magnetnih“ dugmadi ni stalnih animacija.

### 5.7 Reduced motion, failsafe i LCP (sažeto)
- **Reduced motion:** ništa se ne sakriva i ništa ne putuje.
  - reveal je isključen;
  - hero je statičan;
  - meni samo opacity 120 ms;
  - header bez prelaza;
  - pritisak bez pomeranja;
  - CSS keyframes skraćeni na 0,01 ms.
- **Ništa ne ostaje sakriveno:** §5.4, tačke 3 i 6–7. Proverava se e2e testom u K07 (§10.2).
- **LCP** (hero slika ili H1) nikad nije meta skrivanja: na ekranu je pri prvoj odluci, a hero je isključen iz reveal-a.

### 7.2 Broj šasije (`lib/vin.ts`)
- `normalizeVin(s)`: velika slova; uklanja razmake (i U+00A0), crtice, tačke.
- `validateVin(s)` → `{ ok, normalizovan, greska?: "prazan" | "duzina" | "slova-ioq" | "znakovi", duzina, predlog? }`.
  - Dozvoljeno je samo `^[A-HJ-NPR-Z0-9]{17}$`, tačno 17 znakova.
  - **Kontrolna cifra (9. pozicija) se ne proverava** (u Evropi je nema).
  - Predlog: O i Q → 0, I → 1, ako tako postaje ispravan.
- **Poruke** (`content/upit.ts`):
  - dužina: „Broj šasije ima 17 znakova. Upisano je {n}.“
  - I/O/Q: „Broj šasije ne sadrži slova I, O ni Q.“ + „Da li ste mislili {predlog}?“
  - ostali znaci: „Broj šasije sadrži samo slova i brojeve.“
- **Polje VIN:** `autocomplete="off"`, `autocapitalize="characters"`, `spellcheck="false"`, `inputmode="text"`, `maxlength="20"`, prikaz velikim slovima sa `letter-spacing: .06em` i `tabular-nums`, brojač „{n} / 17“.

### 9.2 `scripts/serve-out.mjs` (K02, bez paketa)
- **Argumenti:** `--port 3241` (podrazumevano) i `--dir out`. `http.createServer`; `listen(port)` bez hosta (IPv4 i IPv6).
- **Putanje:**
  - `decodeURIComponent`; `path.resolve` mora ostati unutar `out/` (inače 403);
  - samo `GET` i `HEAD` (inače 405);
  - putanja sa `/` na kraju → `index.html`;
  - fajl postoji → on;
  - nema ekstenzije, a postoji `<putanja>/index.html` → `308 Location: <putanja>/` (kao hosting);
  - inače `out/404.html` sa statusom **404**.
- **MIME:**

  | Ekstenzija | Tip |
  |---|---|
  | `.html` | `text/html; charset=utf-8` |
  | `.css` | `text/css; charset=utf-8` |
  | `.js`, `.mjs` | `text/javascript; charset=utf-8` |
  | `.json`, `.map` | `application/json; charset=utf-8` |
  | `.webmanifest` | `application/manifest+json; charset=utf-8` |
  | `.txt` | `text/plain; charset=utf-8` |
  | `.xml` | `application/xml; charset=utf-8` |
  | `.svg` | `image/svg+xml` |
  | `.png` | `image/png` |
  | `.jpg`, `.jpeg` | `image/jpeg` |
  | `.webp` | `image/webp` |
  | `.avif` | `image/avif` |
  | `.ico` | `image/x-icon` |
  | `.woff2` | `font/woff2` |
  | `.woff` | `font/woff` |
  | ostalo | `application/octet-stream` |

- **Kompresija** (realni Lighthouse): za tekstualne tipove `br` (zlib `brotliCompressSync`, kvalitet 9) ili `gzip` po `Accept-Encoding`, keš u memoriji; `Vary: Accept-Encoding`.
- **Keš:**
  - `/_next/static/*`: `Cache-Control: public, max-age=31536000, immutable`;
  - HTML: `no-cache`;
  - ostalo: `public, max-age=3600`;
  - uvek `X-Content-Type-Options: nosniff`.
- **Kraj:** jedan red loga po zahtevu (status, putanja). Gašenje na SIGINT/SIGTERM. `EADDRINUSE` daje jasnu poruku „Port 3241 je zauzet — ne gasim tuđi proces“ i exit 1.
